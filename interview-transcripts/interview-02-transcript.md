# Fact-Finding: Structured Interview Transcript (Manager)

## 1. Interview Metadata
*   **Date Conducted:** 2026-05-19
*   **Interviewer:** Mr. Chinthana Sandeepa
*   **Interviewee:** Mr. Sanjana De Zoysa 
*   **Target Persona:** Quantity Surveyor (QS) (Web App User) 
*   **Objective:** Understand project setup steps, BOQ import needs, progress calculation logic, and the approval process for daily reports and asset requests .

## 2. Key Findings Summary
*   **Project Setup:** QS need to create projects, assign field supervisors, and set a simple Gantt-style schedule.
*   **BOQ Management:** Work items must be manually entered from the Bill of Quantities (BOQ) so they become trackable tasks for the field team .
*   **Progress Dashboard:** A web dashboard is needed to see today's site progress at a glance without having to make phone calls. This must calculate the overall completion percentage by comparing daily reports against BOQ quantities.
*   **Approvals & Issues:** Managers/QS need alerts for pending reports and requests. They must be able to approve/reject asset requests and view photos of site snags to resolve and close them.

## 3. Interview Transcript

**Interviewer:** Hello Ms. Sanjana. Thank you for your time today. We are building the CivilTrack web application for managers to replace Primavera P6. I have a few questions about how you manage your projects.

**Ms. Sanjana:** Hello! Yes, Primavera P6 is too complex for what we need daily. I need a simpler web dashboard to track my construction sites.

**Interviewer:** Let's start with project setup. What do you need to do when a new project begins?

**Ms. Sanjana:** I need to create the project with basic details like the name, location, and the start and end dates. I also have to assign our supervisors to the project and set up a simple Gantt-style schedule.

**Interviewer:** How do you handle the Bill of Quantities (BOQ)?

**Ms. Sanjana:** That is the most important part. I need to be able to import the BOQ document or manually enter the work items and their quantities. The system must link these BOQ items to the tasks the supervisors report on every day.

**Interviewer:** Understood. When supervisors submit their daily reports, what do you need to monitor on your screen?

**Ms. Sanjana:** I want to see the overall project completion percentage. The system should calculate this by comparing the daily reports to the original BOQ quantities. I also need to track the materials used against our budget, and look at the labour hours logged each day.

**Interviewer:** Supervisors will also submit asset and material requests for the next day. How do you want to manage those?

**Ms. Sanjana:** I need to see a list of pending asset requests on my dashboard. I must be able to quickly approve or reject them so the site work is not delayed. 

**Interviewer:** What about when a supervisor logs an issue or a "snag" on the site?

**Ms. Sanjana:** I need to see the description and the photo they took. Once we sort out the problem, I need a button to mark it as resolved and close the issue.

**Interviewer:** Finally, how do you want to be notified about all these pending items?

**Ms. Sanjana:** It would be great to get simple alerts when I have pending daily reports or asset requests awaiting my review. My main goal is to be able to check today's site progress without calling anyone.

**Interviewer:** Thank you, Ms. Sanjana. Your answers are very helpful for designing the web dashboard!
